Quick Start

O essencial para começar em 5 minutos. Detalhes no Manual do Módulo de Treinos.

Regra de ouro: tudo nasce como rascunho (só a equipe vê). O atleta só vê — e o relógio só recebe — depois de Publicar.

Treinador

Menu Treinos · titular e auxiliar podem tudo

  1. Escolha a turmaSó aparecem turmas com “usa o módulo de treinos” marcado (Turmas → Editar).
  2. Crie o treinoClique no + do dia → título, modalidade, tipo → monte os blocos (contínuo ou intervalado) com alvo em zona — cada atleta recebe o ritmo dele.
  3. PubliqueSalvar e publicar no treino, ou Publicar N rascunhos para a semana toda.
  4. Ajuste para um atleta, se precisarNo treino → aba Atletas → “Ajustar para este atleta”. Não edite o treino da turma.
  5. Dê acesso ao atletaPágina do atleta → card Portal do atleta → Gerar convite → botão do WhatsApp (menor: mande ao responsável).
  6. Acompanhe“Um atleta… → abrir”: feito / não feito, comentários e comparativo. Turma → Desempenho: coluna “Treinos 30d”.

Atleta

No celular · mesmo endereço do sistema

  1. Crie seu acessoAbra o link do convite → escolha nome de usuário (ou e-mail) e senha. Vale 7 dias, uma vez.
  2. EntreTela de login → digite o usuário (ex.: joao.silva) e a senha.
  3. Veja o treino“Próximo treino” no topo; toque para ver os blocos com o seu pace.
  4. Marque como foiFeito, Parcial ou Não fiz + comentário para o treinador.
  5. Opcional: relógioConta → Conectar Intervals.icu (com o Garmin ligado lá). Os treinos vão para o relógio e o que você fizer volta sozinho.

Deu algo errado?

Atleta não vê o treinoEstá publicado? A turma usa o módulo? O cadastro está ativo?
Esqueceu a senhaPágina do atleta → Portal do atleta → Gerar link de nova senha.
Convite não abreVenceu, já foi usado ou foi gerado outro. Gere de novo.
Treino não chegou no relógioAba Atletas do treino: “falhou” → reenviar; “sem Intervals” → atleta não conectou.
Ritmos estranhosAtleta sem teste de campo. Registre o teste ou cadastre o limiar no calendário dele.
Atividade não marcou “feito”Só casa com treino publicado, mesmo dia e modalidade. Senão vira “extra”: abra e vincule.
